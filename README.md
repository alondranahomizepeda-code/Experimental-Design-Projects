# Experimental Design Projects

**Autonomous University of the State of Mexico (UAEMex)** *Faculty of Engineering - Artificial Intelligence Engineering* *Collective Period: 2026A*

This repository contains the practical experimental design projects developed during the semester, focusing on hardware integration, data acquisition, and statistical analysis (ANOVA).

---

## Project 1: Automated Temperature Acquisition System

**Description:** Design and implementation of an automated data acquisition system (DAQ) to monitor thermal gradients in real-time. The system integrates an ESP32 microcontroller, a MAX6675 module, and a K-type thermocouple. Data integrity and thermal stability were validated using statistical variance algorithms programmed in Python, eliminating manual recording errors.

## Final Project: OCR Light Quality Under Variable Lighting

**Description:** A comprehensive one-factor completely randomized experimental design to statistically evaluate how light intensity (measured in Lux) affects the reading precision of an automated billing system. The project utilizes computer vision (OpenCV) and the **GPT-4o Vision** model from Azure OpenAI. The statistical validation (ANOVA) successfully proved the boundaries of the AI model across three operational phases: underexposure collapse, optimal stability, and overexposure degradation.
